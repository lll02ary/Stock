# 台股盤後選股

每個交易日下午 5 點（台北時間），GitHub 會自動幫你：

1. 抓取上市、上櫃所有股票的收盤行情
2. 依照你的三種買進型態篩選並排名
3. 統計今天資金流向哪些族群
4. 綜合兩者，排出最值得留意的前 5 名，**寄到你的 Email**

專案設為私人，只有你看得到程式和結果。

---

## 第一次設定（約 20～30 分鐘，只需要做一次）

### 步驟 1：註冊 GitHub 帳號

到 https://github.com 點右上角 **Sign up** 註冊。

### 步驟 2：建立私人專案（Repository）

1. 登入後，點右上角 **＋** → **New repository**
2. **Repository name** 輸入 `tw-stock-screener`
3. 選擇 **Private**（私人）
4. 勾選 **Add a README file**
5. 按 **Create repository**

### 步驟 3：上傳程式檔案

1. 在專案頁面點 **Add file** → **Upload files**
2. 把這些檔案拖進去：
   `main.py`、`config.py`、`data.py`、`analysis.py`、`report.py`、`requirements.txt`、`README.md`、`.gitignore`
   （`.gitignore` 在 Mac 的 Finder 預設看不到，沒傳也沒關係）
3. 按下方綠色 **Commit changes**

### 步驟 4：建立自動排程檔（最重要的一步）

這個檔案放在隱藏資料夾裡，用拖曳上傳常會失敗，所以改用手動建立：

1. 點 **Add file** → **Create new file**
2. 檔名欄位輸入：`.github/workflows/daily.yml`
   （輸入到 `/` 時，GitHub 會自動幫你建立資料夾，這是正常的）
3. 用記事本打開 `daily.yml`，全部複製後貼到下方的編輯區
4. 按 **Commit changes**

### 步驟 5：建立 Gmail 應用程式密碼

程式需要用你的 Gmail 寄信，但不能用你平常的密碼，要另外產生一組「應用程式密碼」：

1. 到 https://myaccount.google.com/security ，確認「兩步驟驗證」已開啟（沒開的話先開啟）
2. 到 https://myaccount.google.com/apppasswords
3. 名稱輸入 `台股選股`，按 **建立**
4. 畫面會出現一組 16 個字母的密碼，**先複製起來**（關掉後就看不到了）

> 建議用一個專門寄信的 Gmail，不一定要用你的主要信箱。

### 步驟 6：把密碼存進 GitHub（Secrets）

Secrets 是 GitHub 的加密保險箱，存進去之後連你自己都看不到內容，程式碼裡也不會出現你的密碼。

1. 在專案頁面點上方 **Settings**
2. 左側選 **Secrets and variables** → **Actions**
3. 按綠色 **New repository secret**，依序新增三個：

| Name（照抄） | Secret（填入） |
|---|---|
| `MAIL_USERNAME` | 寄信用的 Gmail 地址 |
| `MAIL_PASSWORD` | 步驟 5 的 16 碼應用程式密碼 |
| `MAIL_TO` | 收報告的信箱（多個用逗號分隔，可以跟寄信的同一個） |

### 步驟 7：第一次手動執行

1. 點專案上方的 **Actions**
2. 左側點 **台股盤後選股**
3. 右側按 **Run workflow** → 再按綠色 **Run workflow**
4. 等它跑完：第一次要抓約 5 個月的歷史資料，大約 **15～20 分鐘**；之後每天只要幾分鐘
5. 出現綠色勾勾 ✅，並收到 Email，就代表成功

> 手動執行時，如果今天還沒收盤或是假日，會改用最近一個交易日的資料寄報告，方便你確認設定正確。每天下午 5 點的自動執行，遇到休市就不會寄信。

設定完成！之後每個交易日下午 5 點後就會收到報告。

---

## 報告內容

Email 內文包含：

- **今日最該留意的 5 檔**：每檔附入選理由、所屬族群熱度排名
- **資金輪動族群排名**：哪些族群今天資金流入最多
- **符合買進型態的股票**：趨勢扭轉、箱型量增，依分數排序
- **空頭爆量搶反彈**：另外列出，並標示 K 棒型態

附件有兩個檔案：

- `report_日期.html`：完整版報告（含選股規則說明），用瀏覽器開啟，手機也能看
- `candidates_日期.csv`：所有候選股清單，可以用 Excel 開啟自己排序篩選

過去 30 天的報告也可以在 **Actions** → 點某一次執行 → 頁面下方 **Artifacts** 下載。

## 調整選股參數

所有數字都在 `config.py`，每一項都有中文說明。修改方式：在 GitHub 上點開 `config.py` → 右上角鉛筆圖示 → 修改 → **Commit changes**，下次執行就會套用。

常調整的項目：

| 參數 | 預設 | 說明 |
|---|---|---|
| `MIN_AVG_VOLUME_LOTS` | 500 | 5 日均量門檻（張） |
| `TURN_MIN_DAYS_BELOW` | 5 | 趨勢扭轉：站上前至少幾天在均線下 |
| `REBOUND_VOLUME_RATIO` | 2.0 | 搶反彈：爆量倍數 |
| `BOX_DAYS` | 60 | 箱型觀察天數 |
| `BOX_MAX_RANGE_PCT` | 15 | 箱型最大震幅（%） |
| `GROUP_HEAT_MAX_BOOST` | 0.5 | 族群熱度最多讓分數放大幾成 |

## 調整執行時間

打開 `.github/workflows/daily.yml`，修改這一行：

```
- cron: "0 9 * * 1-5"
```

GitHub 用的是 UTC 時間，比台灣慢 8 小時。例如想改成台灣 16:30，就是 UTC 08:30，寫成 `"30 8 * * 1-5"`。不建議早於 16:00，櫃買中心資料有時較晚公布。

GitHub 的排程在尖峰時段可能延遲幾分鐘到半小時，屬於正常現象。

## 常見問題

**Actions 出現紅色叉叉 ❌**
點進去看「執行選股並寄出 Email」那一步的錯誤訊息：

- `尚未設定 GitHub Secrets`：步驟 6 的三個名稱要完全照抄（全大寫、底線）。
- `Username and Password not accepted`：密碼要用步驟 5 的應用程式密碼，不是 Gmail 登入密碼。
- `多次重試仍無法取得資料`：證交所暫時擋住太頻繁的連線，等 30 分鐘後手動按 Run workflow 即可，已抓到的資料不會不見。

**沒收到信**
先看垃圾郵件匣，把寄件地址加入聯絡人。

**私人專案會不會被收費？**
不會。免費帳號的私人專案每月有 2,000 分鐘的執行額度，這支程式每天約 3～5 分鐘，一個月約 100 分鐘。

**歷史資料重新抓取**
歷史資料存在 GitHub 的快取裡，超過 7 天沒使用會被清除。每個平日都會執行，所以正常情況不會發生；若被清除，程式會自動重新抓取，那一次會跑比較久。

## 目前的限制

- 股價沒有做除權息還原，除權息當天的跳空可能讓均線短暫失真，看到剛除權息的股票入選時可以多留意。
- 族群使用證交所官方產業分類（如半導體業、電子零組件業），不包含市場自訂的概念股（如 AI 伺服器、重電）。
- 全額交割股沒有特別排除，但這類股票成交量通常很低，大多會被 500 張的門檻擋掉。
- 本程式只依技術條件篩選，不代表股票一定會漲，買賣決定請自行判斷。
